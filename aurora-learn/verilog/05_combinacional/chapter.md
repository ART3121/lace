# Circuitos combinacionais

Num circuito combinacional, as saídas dependem só dos valores atuais das entradas: não há memória nem clock. Até aqui, cada saída foi uma expressão num `assign`. Neste capítulo você descreve circuitos com o bloco `always @(*)`, com `case` e com `if`, usa os operadores de comparação e de deslocamento e monta peças que aparecem em qualquer projeto digital: multiplexador, decodificador, codificador de prioridade, comparador, o decodificador de um display de sete segmentos e o conversor para código Gray.
