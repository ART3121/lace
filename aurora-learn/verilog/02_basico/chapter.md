# Portas lógicas

Cada porta lógica tem um operador em Verilog: `&` para E, `|` para OU, `^` para OU exclusivo e `~` para NÃO. Com esses operadores e com parênteses se escreve qualquer função de bits. Neste capítulo você escreve portas, liga várias saídas no mesmo módulo, dá nome a resultados intermediários com fios internos e traduz para Verilog regras escritas em português.
