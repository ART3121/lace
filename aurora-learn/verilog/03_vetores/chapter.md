# Vetores

Um vetor é um grupo de fios com um nome só. A declaração `[7:0]` cria oito bits, numerados do 7, o mais significativo, ao 0, o menos significativo. Neste capítulo você seleciona bits e faixas de vetores, aplica operadores a todos os bits de uma vez, junta vetores com a concatenação e repete bits com a replicação.
